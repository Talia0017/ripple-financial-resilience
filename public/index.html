这些财务指标是什么意思？
I · 典型月收入
所有已有月份 money_in 的中位数。
S · 典型月支出
money_out 的中位数，已经包含贷款付款。
F · 典型固定开支
先逐月相加 household_bills + insurance + loan_payments，再取中位数。不能把三个字段的中位数直接相加。
B · 储蓄缓冲金
按月份排序，最后六行 avg_daily_balance 的平均值。不足六个月使用已有月份并提示。这是历史余额代理值，不是实时可用存款。
H · 家庭账单
household_bills 的中位数。
P · 贷款月供
截至 2025-12-31 已开始、状态为 C/D 的贷款 monthly_payment 之和。A/B 为 0，无贷款记录为 0，未知数据不假设为 0。P 和 F 不再额外加到支出 S。

中位数就是把各月金额排序后取中间值。缺失金额不补成 0；相关指标使用有效记录并显示限制。B 不向六行窗口以外借用旧值。

官方续航公式与模型限制

buffer_left = B − one_off_costs

gap = spending_after − income_after

① buffer_left ≤ 0 → 0 个月

② 否则 gap ≤ 0 → No shortfall (120+)

③ 其他情况 → min(buffer_left / gap, 120)

“No shortfall (120+)”是比赛标签，表示当前固定参数下没有月度缺口，不表示未来 120 个月都有保障。缓冲金已耗尽时，即使月收入足够支付月开支，也按官方规则显示 0。

本模型不核验 EI 资格、上限或发放期限，不模拟税费、利息、通胀和行为变化，也不是逐月现金流预测。个性化储蓄目标和备用计划将在下一阶段实现。
